05 — faq

Yang sering ditanya.

Kenapa klik di sekitar pill tembus ke bawah?

Itu maunya Musa. Hanya pill-nya yang menerima klik, area transparan di sekitarnya diteruskan ke aplikasi di bawah. Jadi overlay tidak pernah menghalangi kerja.

Bedanya sembunyi otomatis vs sembunyi paksa?

Otomatis: pill muncul lagi saat kursor menyentuh tepi atas. Paksa: dikunci sembunyi sampai kamu tampilkan manual via tray atau Ctrl+Shift+M. Tiap restart selalu mulai tampil.

Kenapa ada peringatan saat install?

Karena build v1 belum ditandatangani (unsigned). Di Windows pilih More info → Run anyway, di macOS klik kanan → Open. Pastikan file dari halaman ini dan cocokkan checksum di halaman rilis.

Apakah dataku dikirim ke mana-mana?

Tidak. Stats, timer, dan setting tersimpan lokal sebagai JSON. Satu-satunya koneksi adalah saat kamu menekan tombol cek update. Detail: Kebijakan Privasi.

Di mana log kalau ada masalah?

Windows: %LOCALAPPDATA%\com.musa.app\logs\musa.log · macOS: ~/Library/Logs/com.musa.app/musa.log.
