Tutorial Install + FAQ

Panduan install Musa v1 untuk Windows, macOS ARM, dan Linux. Versi dan link file di halaman ini terisi otomatis dari feed version.json — selalu menunjuk ke rilis terbaru.

Musa v1 itu UNSIGNED. Peringatan SmartScreen (Windows) dan Gatekeeper (macOS) itu normal — bukan file rusak, bukan virus. Kuncinya: unduh dari halaman resmi ini dan cocokkan hash SHA-256 sebelum install (Langkah 0).

1. File per OS

Sumber: GitHub Releases (Lihat semua file →). Setiap target CI ditemani file SHA256SUMS-<target>.txt sebagai pembanding hash.

OSFileTarget CISHA-256
Windows x64 memuat… x86_64-pc-windows-msvc SHA256SUMS.txt
Windows x86 memuat… i686-pc-windows-msvc SHA256SUMS.txt
macOS ARM memuat… aarch64-apple-darwin SHA256SUMS.txt
macOS ARM memuat… aarch64-apple-darwin SHA256SUMS.txt
Linux x64 memuat… x86_64-unknown-linux-gnu SHA256SUMS.txt
Linux x64 memuat… x86_64-unknown-linux-gnu SHA256SUMS.txt

macOS hanya untuk Apple Silicon (M1+) — belum ada build Intel. Linux ditargetkan untuk Ubuntu 22.04 x64. Tabel checksum lengkap juga ada di halaman rilis.

2. Langkah 0 — verifikasi hash

Ganti NAMA_FILE dengan nama file yang kamu unduh (lihat tabel di atas), lalu bandingkan hasilnya dengan isi SHA256SUMS-<target>.txt atau tabel checksum di halaman rilis. Cocok = file utuh dan asli.

Windows (PowerShell)

certutil -hashfile NAMA_FILE.exe SHA256

macOS (Terminal)

shasum -a 256 NAMA_FILE.dmg

Linux (Terminal)

sha256sum NAMA_FILE.deb
# atau: sha256sum NAMA_FILE.AppImage

3. Windows

  • WebView2 sudah bawaan Windows 11 — tidak perlu install tambahan.
  • Installer per-user, tanpa admin. Jalankan .exe seperti biasa, pilih folder install, selesai.
  • SmartScreen: layar biru “Windows protected your PC” → More info → Run anyway. Itu normal untuk build unsigned.
  • Uninstall: Settings → Apps → Installed apps → Musa → Uninstall.

4. macOS (Apple Silicon)

  • Buka .dmg, drag Musa ke Applications. Jangan dijalankan langsung dari dalam DMG — eject DMG setelah selesai.
  • Buka pertama: klik kanan app → Open → Open (sekali saja, selanjutnya normal).
  • Error “Musa is damaged and can’t be opened. You should move it to the Trash” = Gatekeeper menolak app unsigned, bukan file korup. Fix via Terminal:
    sudo xattr -rd com.apple.quarantine /Applications/Musa.app
  • Alternatif tanpa Terminal: System Settings → Privacy & Security → Open Anyway.
  • Ciri normal: tanpa ikon Dock, hanya ikon tray hitam-putih. Kalau tidak ada jendela setelah dibuka, itu memang maunya begitu — cek tray atau tekan Ctrl+Shift+M.

5. Linux (Ubuntu 22.04 x64)

  • Pilih salah satu — install .deb:
    sudo apt install ./musa_*_amd64.deb
    atau portable AppImage:
    chmod +x Musa_*.AppImage && ./Musa_*.AppImage
  • Batasan v1: Now Playing, Mixer volume, quick actions, dan keep-awake masih stub — UI-nya hide/disable, bukan bug.
  • X11 disarankan. Wayland belum tentu jalan penuh — wajib smoke-test di mesin nyata: cek ikon tray muncul, pill tampil di tepi atas, dan klik-tembus bekerja.

6. FAQ

Apakah file-nya berbahaya? Kok ada peringatan?

Tidak. Peringatan muncul karena Musa v1 unsigned (belum ditandatangani + belum dinotarisasi), jadi SmartScreen/Gatekeeper tidak mengenali reputasinya. Selama file dari halaman resmi ini dan hash SHA-256 cocok (Langkah 0), file aman.

macOS bilang “damaged” dan suruh Trash. File-nya korup?

Bukan korup — itu pesan Gatekeeper untuk app unsigned. Kalau hash SHA-256 cocok, file utuh. Fix: sudo xattr -rd com.apple.quarantine /Applications/Musa.app, atau System Settings → Privacy & Security → Open Anyway.

Apakah bisa build sendiri dari source?

Tidak — Musa itu closed source (proprietary), tidak ada source publik. Satu-satunya cara resmi adalah binary dari halaman ini / GitHub Releases, lalu verifikasi hash-nya (Langkah 0).

Perlu admin / root?

Windows tidak (per-user). macOS umumnya tidak, kadang butuh password admin saat copy ke Applications. Linux: .deb butuh sudo, AppImage tidak.

Ada build Intel Mac / 32-bit / distro lain?

macOS: ARM M1+ saja, belum ada build Intel. Windows: tersedia x64 dan x86 (32-bit). Linux: target Ubuntu 22.04 x64 — distro lain silakan coba AppImage, tanpa garansi.

Bagaimana cara update?

v1 masih manual: buka Settings → General → Update di aplikasi untuk cek versi terbaru (mengambil feed version.json). Unduh installer baru dan install di atas versi lama — setting JSON terbawa otomatis.

App tidak terlihat setelah install. Ke mana?

Musa hidup di tray tanpa jendela utama. Cek ikon tray, atau tekan Ctrl+Shift+M sebagai jalur darurat. Kalau tetap hilang, cek log — Windows: %LOCALAPPDATA%\com.musa.app\logs\musa.log · macOS: ~/Library/Logs/com.musa.app/musa.log.

Apakah Start at login nyala sendiri?

Tidak — default mati. Nyalakan manual dari Settings atau menu tray kalau mau Musa jalan tiap boot.
