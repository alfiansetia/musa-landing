Kebijakan Privasi

Berlaku mulai 22 Oktober 2026. Versi singkatnya: Musa tidak mengumpulkan datamu — tidak ada akun, tidak ada analytic, tidak ada pelacakan, tidak ada iklan.

1. Data berjalan dan tersimpan lokal

  • Pengaturan tersimpan sebagai file JSON di perangkatmu dan terbawa saat update manual.
  • Statistik CPU / RAM / baterai diambil tiap 2 detik untuk tampilan pill saja — tidak disimpan ke file dan tidak dikirim ke mana pun.
  • Now Playing (judul, artis, artwork) dibaca dari sistem operasimu saat itu juga; artwork di-cache di memori saja dan hilang saat aplikasi ditutup.
  • Log aplikasi hanya ada di perangkatmu — Windows: %LOCALAPPDATA%\com.musa.app\logs\musa.log, macOS: ~/Library/Logs/com.musa.app/musa.log — dan bisa kamu hapus kapan saja.

2. Satu-satunya koneksi jaringan

Musa hanya terhubung ke internet saat kamu manual menekan tombol cek pembaruan (Settings → General → Update). Saat itu aplikasi mengambil satu file kecil (version.json) untuk membandingkan versi. Tidak ada unduh otomatis, tidak ada install otomatis, tidak ada telemetri, tidak ada crash report otomatis.

3. Situs unduhan ini

Halaman ini situs statis: tanpa cookie pelacakan, tanpa akun, tanpa form yang menyimpan data. Penyedia hosting/tunnel di baliknya dapat mencatat log teknis standar (misalnya alamat IP dan waktu akses) — itu di luar kendali kami dan tidak dipakai untuk profiling.

4. Hapus datamu

Karena tidak ada data di server kami, tidak ada yang perlu diminta untuk dihapus. Uninstall aplikasi lalu hapus file settings dan log di perangkatmu — selesai, tidak ada sisa di pihak kami.

5. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal berlaku di atas diperbarui dan perubahan signifikan diumumkan di halaman rilis.
