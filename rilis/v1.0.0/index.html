Yang berubah

  • Overlay pill ala Dynamic Island: hover mengembang, klik di luar pill tembus
  • Statistik CPU / RAM / baterai live tiap 2 detik
  • Now Playing via SMTC (Windows): artwork, transport, seek, shuffle, repeat
  • Countdown timer + stopwatch, deadline aman dari collapse
  • Keep-awake sesi, quick actions, tray + hotkey Ctrl+Shift+N
  • Jendela Settings + cek pembaruan manual

Catatan install

  • Windows: NSIS per-user, tanpa admin. WebView2 sudah bawaan Windows 11.
  • macOS: seret ke Applications. Build unsigned → klik kanan → Open pada buka pertama.
  • Linux: Now Playing / Mixer / quick actions / keep-awake adalah stub (UI hide/disable).
  • Update manual: install versi baru di atas versi lama, setting JSON terbawa.
