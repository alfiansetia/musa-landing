Catatan install

  • Windows: NSIS per-user, tanpa admin. WebView2 sudah bawaan Windows 11.
  • macOS: seret ke Applications. Build unsigned → klik kanan → Open pada buka pertama.
  • Linux: Now Playing / Mixer / quick actions / keep-awake adalah stub (UI hide/disable).
  • Update manual: install versi baru di atas versi lama, setting JSON terbawa.
