Catatan install

  • Windows: NSIS per-user, tanpa admin. WebView2 sudah bawaan Windows 11; mesin lama mengunduh runtime saat install.
  • macOS: seret ke Applications. Build unsigned → klik kanan → Open pada buka pertama.
  • Linux: Now Playing / Mixer / quick actions / keep-awake adalah stub (UI hide/disable). Tray icon tergantung desktop (GNOME butuh ekstensi AppIndicator).
  • Update selalu manual: install versi baru di atas versi lama, setting JSON terbawa.

Checksum (SHA-256)

Isi setelah artifacts final dari CI. Contoh format:

<sha256>  Musa_1.0.0_x64-setup.exe
<sha256>  Musa_1.0.0_x86-setup.exe
<sha256>  Musa_1.0.0_aarch64.dmg
<sha256>  musa_1.0.0_amd64.deb
<sha256>  Musa_1.0.0_amd64.AppImage
