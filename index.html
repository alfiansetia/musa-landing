Fitur

Semua berjalan lokal di mesinmu. Tidak ada akun, tidak ada analytic, tidak ada server.

Pill yang tahu diri

Collapsed mungil (compact / regular / large), mengembang saat hover, menciut saat kursor pergi. Easing spring, bisa reduce-motion.

Click-through

Hanya pill yang menerima klik. Area transparan di sekitarnya tembus ke desktop — overlay tidak pernah menghalangi kerja.

Statistik 2 detik

Satu metrik di pill ciut: CPU / RAM / baterai (default CPU). Sampling native tiap 2 detik, slot baterai kosong otomatis di PC tanpa baterai.

Now Playing

Windows via SMTC: judul, artis, artwork, play/pause/skip, seek bar, shuffle, repeat, rate. Kontrol yang tidak didukung player tampil disabled.

Timer & stopwatch

Preset 5 / 10 / 25 menit plus stopwatch. Deadline hidup di Rust — collapse atau reload webview tidak me-reset. Pill berdenyut sekali saat selesai.

Keep awake sesi

Ikon matahari menahan system sleep selagi aktif (display sleep tetap boleh). Selalu mati tiap launch — bukan setting permanen.

Quick actions

Task Manager, kunci layar, dan shortcut ke pengaturan Do Not Disturb — sekali klik dari header expanded.

Tray + hotkey + autostart

Tray: Autohide / Force hide / Force show / Settings / Start at login / Quit. Hotkey global Ctrl+Shift+N sebagai jalur darurat. Autostart per-user, nonaktif di portable mode.

Cara pakai

  1. Install — Windows: jalankan NSIS per-user. macOS: seret .app ke Applications, klik kanan → Open sekali. Linux: install .deb atau chmod +x AppImage.
  2. Hover pill di tengah atas layar untuk membuka panel. Tinggalkan untuk menciutkan.
  3. Atur lewat ikon gear: layar follow-cursor, ukuran pill, offset, opasitas, autostart. Update dicek manual dari Settings.

FAQ

Kenapa klik di sekitar pill tembus ke bawah?

Itu invarian inti Musa. Frontend melaporkan rect pill ke Rust tiap frame, lalu thread hit-test mengalihkan ignoreCursorEvents saat kursor di luar pill. Jadi overlay selebar 520px tapi hanya pill yang interaktif.

Bedanya Autohide, Force hide, dan Force show?

Autohide: pill sembunyi saat kursor pergi, muncul lagi saat kursor menyentuh tepi atas. Force hide: sembunyi dan dikunci — zona reveal autohide ikut nonaktif sampai kamu show manual. Force show (juga via tray / Ctrl+Shift+N / Settings): membuka kunci dan menampilkan lagi. Status force hanya sesi ini; restart selalu mulai tampil.

Fitur apa yang terbatas di Linux?

Now Playing disembunyikan (tidak ada SMTC), Mixer “unavailable”, quick actions mengembalikan error, dan keep-awake disabled. UI-nya otomatis hide/disable — itu stub yang disengaja, bukan bug. Overlay transparan + click-through wajib dites di mesin asli (X11 vs Wayland, ikon tray tiap desktop).

Kenapa Windows/macOS menampilkan peringatan saat install?

Karena build v1 unsigned: belum ada Authenticode (Windows) dan belum notarization (macOS). Di macOS, klik kanan → Open, atau xattr -dr com.apple.quarantine Musa.app untuk build lokal. Jangan distribusikan sebagai rilis resmi sebelum signing.

Apakah ada auto-update?

Tidak di v1 — by design. Settings → General → Update hanya membandingkan version.txt di repo dengan versi berjalan, lalu mengarahkanmu download manual dari halaman rilis. Tidak ada yang diunduh/diinstall otomatis.

Bagaimana autostart & portable mode?

Start at login tersedia di tray dan Settings, off by default, registrasi per-user (Windows: HKCU…\Run, macOS: LaunchAgent). Portable jika NOTCH_PORTABLE=1 atau ada file portable di sebelah executable — menu autostart terkunci.

Apakah dataku keluar dari mesin?

Tidak. Stats, media (artwork 2 MB di-cache di memori saja), timer, dan settings JSON semuanya lokal. Satu-satunya network adalah cek versi manual ke raw.githubusercontent.com saat kamu menekan tombol update.

Di mana log kalau ada masalah?

Windows: %LOCALAPPDATA%\com.musa.app\logs\musa.log. macOS: ~/Library/Logs/com.musa.app/musa.log. Frontend error ikut diteruskan ke file yang sama.
